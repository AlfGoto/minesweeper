# Tabs

Switches between panels of one page: shadcn `ui/tabs`.

Used by the /skins Collection (Grid, Backgrounds, Banners) and /stats. The list is a `muted` track; the active trigger is white with `shadow-sm`. On /skins the list is a segmented control (`max-w-md`) on the page background, with a `text-4xl` bold title and description under it (no wrapping card).
