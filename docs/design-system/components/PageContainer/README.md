# PageContainer

The shell of every content page: `components/page-container.tsx`.

"Back to game" button top-right, then the content in a white card (`border`, `radius-lg`, 16px padding, 32px on md+). Widths: `narrow` 768px, `default` 896px, `wide` 1152px. The card is what keeps text readable whatever background skin the player has.
